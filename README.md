# Excel Pivot Dashboard Project

Taksi verilerini analiz etmek ve görselleştirmek için oluşturulan interaktif Excel Pivot Dashboard projesi.

##  Proje Hakkında

Bu proje, büyük ölçekli taksi veri setini kullanarak:
- **Veri analizi** ve görselleştirme
- **Pivot tablo** oluşturma
- **Dashboard** hazırlama
- **İş içgörüsü** (business intelligence) sağlama

amaçlarıyla oluşturulmuştur.

## Proje Yapısı

```
excel-pivot-dashboard-project/
├── taxi veri seti/     # Taksi veri setleri
└── README.md           # Bu dosya
```

##  Başlarken

### Gereksinimler
- Microsoft Excel 2016 veya sonrası
- veya LibreOffice Calc
- veya Google Sheets

### Kurulum
1. Repoyu klonlayın
```bash
git clone https://github.com/aysenuroguz12/excel-pivot-dashboard-project.git
```

2. Proje klasörüne gidin
```bash
cd excel-pivot-dashboard-project
```

3. Excel dosyalarını açın ve pivot tabloları inceleyebilirsiniz
